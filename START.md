## Adding Substack Recipes

1. Open the Meal Planner → **Substacks** tab
2. Add a publication name + URL (e.g. `https://example.substack.com`)
3. Click **Refresh All Feeds** to load recent posts
4. Click **+ Add as Recipe** on any post
5. Fill in macros + ingredients → **Save to Recipe Library**

Or run the fetcher manually:
```bash
python3 scripts/fetch_substacks.py
```
