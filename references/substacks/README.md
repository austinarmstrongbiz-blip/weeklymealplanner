# Drop Substack PDFs here

Restaurant Dropout's paid posts are locked. Claude cannot read them from the web, even though you pay.

## What to do each Friday

1. Open the new Restaurant Dropout post in Chrome (logged in, so you see the full recipes).
2. Press **Cmd + P**.
3. Change destination to **Save as PDF**.
4. Save it into this folder.
5. Name it `YYYY-MM-DD_short-slug.pdf`

Example: `2026-08-07_caroline-chambers.pdf`

That's it. About 20 seconds.

## What Claude does with it

Every time the weekly meal planner runs, it checks this folder, reads any PDF from the last 21 days, and pulls the recipe names, ingredients, and techniques into that week's inspiration list. Recipes get adapted to your and Cameron's macros, never used verbatim.

If the folder is empty or the newest PDF is stale, Claude will say so in chat and fall back to seasonal produce plus the cuisine rotation.
